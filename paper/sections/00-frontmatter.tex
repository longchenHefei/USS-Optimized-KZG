
\begin{abstract}
Updatable Secure Storage (USS) enables a client to outsource dynamic encrypted databases, maintain a single constant-size local stub, and detect server-side state-rollback attacks—even after secret keys are compromised. To enable server-side key rotation without downloading and re-encrypting payloads, USS integrates Updatable Encryption (UE). However, existing USS constructions remain impractical. The pioneering scheme by Chen, Guo, Li, and Tang (CGLT23, ASIACRYPT 2023) relies on a Catalano--Fiore Homomorphic Vector Commitment (HVC) with a quadratic $O(n^2)$ Common Reference String (SRS)—requiring tens of megabytes at vector dimension $n=1024$ and becoming prohibitive at $n=2^{14}$—while leaving the Data Encapsulation Mechanism (DEM) unmeasured for large payloads.

We present $\mathsf{KHVC}$, a KZG-based homomorphic vector commitment with an $O(n)$ SRS, $q$-SDH position binding, and statistical position hiding in CGLT23's exact Figure~6 view. At $n=1024$, $\mathsf{KHVC}$ reduces operational parameters from $50.5\,\text{MB}$ to $96.3\,\text{KB}$ and supports closed-form one-hot opening updates.

For bulk payloads, we use Ring-LWR with shared public block polynomials and independent RLWE-encrypted file masks. We first prove that CGLT23's literal one-hop exposure rule admits a universal two-transition attack against every correct publicly updatable USS. We therefore prove IND-DD-UP, IND-FileUp-CPA, and IND-REENC-CPA in the repaired transitive-closure game, with consistent direct-disclosure bookkeeping, adaptive key and token exposure, disconnected post-challenge key leakage, and delayed FileUp-transcript disclosure. The proof uses protected exposure components, right-to-left shadow-header simulation, multi-sample Ring-LWR body hybrids, and a DDH opening-ciphertext reduction; it imposes no suffix restriction. Each rotation also adds independent wide noise. The resulting multi-file statistical simulation supplies the joint phase-residual step at a hidden real-key boundary and has an explicit accumulated bound. With $N_H=16384$ and a 256-bit header modulus, the deterministic correctness budget retains 127 rotations per file version; each header is 1 MiB and the shared epoch token is 65.004 MiB. Fresh FileUp opening blinding repairs the earlier source-comparison attack, and an independent OF-PTXT proof permits arbitrary epoch-key leakage.
\end{abstract}

\noindent\textbf{Keywords:} vector commitment, KZG, updatable encryption, updatable secure storage, key rotation.
